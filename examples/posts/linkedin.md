When I film one video, I still have to write a Threads post, a Naver blog post and an X post from it. Every platform has its own rules.

So I made a writing employee. I give it my video, my subtitles or my notes, and it writes a post for each platform in my own voice, with pictures made from my real material.

Threads takes 500 characters. X takes 280, but it counts each Korean letter as 2, so about 140 Korean letters fit. It counts that for me.

It never makes up a person, a screen or a number. Before anything goes out it checks the text, and in the browser it stops right before the post button. I post it myself.
