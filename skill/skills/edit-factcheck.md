# Skill: edit + fact-check

Edit passes adapted from coreyhaines31/marketingskills (MIT): clarity, voice, so what, prove it, specific, feeling, risk.

1. `CW check <run> --trace` (or `CW factcheck <run>`): every rule, plus where every number in every post comes from (a fact sheet line, a source id, or a time in the video). "NOT FOUND" means take it out or find the source.
2. Read the post seven times, each time for one thing: is it clear; is it the user's voice; does each part matter to the reader; is every claim backed (a source, a number, a quote); is it specific (names, numbers, scenes, not "다양한"); does it make the reader feel something real; could anything get the user in trouble (a promise, a health or money claim, someone else's words as fact).
3. A change you cannot say is better (not just different) goes back.
4. Build again; no FIX left.
